rclone — personal Google Drive connection

A personal connection run by Fletcher Crebert, using rclone and Rclone UI on his computer to work with Google Drive accounts he authorizes.

What it does

The OAuth application is named rclone. It lets the local software browse files, make bulk copies and downloads, and transfer files to destinations the user chooses. Uploading, organizing, renaming or deleting files is available when the authorized permissions allow those actions.

Google authorization connects the account to the local rclone setup. This website provides information about that personal configuration.

Your accounts, your choices

The account owner chooses which accounts to connect, which permissions to grant and which operations to run. Review the privacy information for details about data access and storage, and the terms information for operating this setup.
