Privacy

This policy describes the personal OAuth application named rclone, run by Fletcher Crebert using local rclone and Rclone UI software.

Data access and use

Depending on the permissions granted, rclone can access Google Drive filenames, folder information, file metadata and file contents. The data is used to browse and manage authorized accounts and perform the file operations the user requests, including copies, downloads, uploads and transfers to chosen destinations.

Storage and sharing

OAuth credentials and tokens are stored in the local rclone configuration. File information may also appear in local caches or logs. Downloaded files and transferred copies are stored in the folders, devices or remote services the user selects, where they remain until removed under those destinations’ retention settings.

This personal configuration does not sell Google user data or use it for advertising or AI training. Transfers to other storage services occur through the operations and destinations the user chooses. Those services have their own data practices.

Stopping access and removing data

The account owner can revoke authorization through Google Account connections and remove the remote connection and credentials from the local rclone configuration. Retained files, caches, logs and backups can be removed separately. Revoking access or removing a connection does not delete copies already saved elsewhere.

This documentation website

The public website contains static information. It has no sign-in or upload form and no facility to submit OAuth credentials, tokens or Drive contents. No analytics or tracking scripts have been added.

GitHub Pages hosts the site. GitHub logs visitors’ IP addresses for security purposes, as explained in its Pages documentation and privacy statement. Public repository content and support issues are visible to others; keep private data out of them.
